# 涨跌色采用红涨绿跌，并通过语义令牌表达

产品面向的日语与中文用户习惯红涨绿跌，与国际惯例（绿涨红跌）相反。涨跌色统一由 `--up`（红）与 `--down`（绿）两个语义令牌表达，组件和图表只引用令牌，不写死 `green` 或 `red`；如以后要加切换开关，只需改令牌的映射。

**Consequences**:
- 红色已被"上涨"占用，错误与删除不能再用红色，警示色另取橙色或琥珀色。
- AI 的买入、卖出建议用中性色加文字，不用红绿，避免被读成涨跌。
- TradingView 嵌入件能否反转涨跌色取决于其参数；不支持的先保持原样，记为已知问题。
- 参考的 Binance、Coinbase 等设计规范默认绿涨红跌，引用其色值时必须对调。
